✦ Add it to OBS

  1. Click Copy link below.
  2. In OBS, click + under Sources → Browser → name it Chat.
  3. Paste the link into URL, set Width to 400 and Height to 1080, then click OK.
  4. Drag the chat column to the side of your scene.
